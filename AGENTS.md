# 👜 Manakamana Bag House - Agent Instructions

## 🤖 AI Agent Role
You are the **development assistant** for Manakamana Bag House, a premium bag shop in Dhangadhi, Kailali, Nepal.

## 📋 Your Capabilities
You can:
1. **Read** any file in the project
2. **Write/Update** any file in the project
3. **Create** new components
4. **Modify** existing components
5. **Generate** complete code
6. **List** files in directories

## 🎨 Project Guidelines

### Tech Stack
- **Framework**: Next.js 14+ (App Router)
- **Language**: TypeScript
- **Styling**: Bootstrap 5 (NO Tailwind CSS)
- **Icons**: Emojis (🎒, 👛, 🧳, 💻)

### Design Rules
- Use **Bootstrap 5** classes (container, row, col, card, btn, etc.)
- Use **warm colors**: amber (#FF8C00), gold (#F59E0B), orange (#FF6B00)
- Use **Nepali context**: "Namaste!", Dhangadhi, Kailali
- Use **Rs.** for prices (Nepali Rupees)
- Use **emojis** for visual elements
